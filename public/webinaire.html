Page 03 : Webinaire / Live

La preuve, pas la promesse.

Plutôt que de décrire le format live, on le tourne. Vidéo présentée en anglais, dans la langue prévue pour le département, comme XTB ou SaxoStrats.

Emplacement vidéo

Dépose ton fichier dans /public/video/pitch.mp4 puis remplace ce bloc par la balise <video> (voir commentaire dans le code source).

Pourquoi en anglais

C'est la langue prévue pour le département dès le départ. Le prouver directement dans cette démonstration retire toute ambiguïté sur la capacité à produire ce format à ce niveau.

Ce que ça démontre

Une présence caméra, une structure d'analyse claire, et un format reproductible chaque semaine : la base d'un programme de live récurrent.
